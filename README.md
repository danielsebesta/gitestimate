# GitEstimate

Estimate how long a GitHub repo took from its commit history.

Runs in the browser. Public repos need no token; private repos use OAuth
or a [fine-grained PAT](https://github.com/settings/tokens).

Shareable links: `/owner/name` or `?repo=owner/name`. Static hosts need an
SPA fallback for path links (see **Deploy**).

## Private repos — OAuth

**Sign in with GitHub** is the primary path. **Device code** is a backup.
Token exchange goes through `/api/oauth` so the client secret stays server-side.

Setup (once):

1. [Create an OAuth App](https://github.com/settings/developers).
   - Homepage / Redirect URI: `https://gitestimate.sebesta.dev/`
     (add `http://localhost:5173/` for local web sign-in).
   - Enable **Device Flow** (for the backup button).
   - Leave **Expire user access tokens** off (no refresh handling yet).
2. `.env` (see `.env.example`):
   ```
   VITE_GITHUB_CLIENT_ID=Ov23…
   GITHUB_CLIENT_SECRET=…   # never VITE_ — server only
   ```
3. Production secret on the Worker:
   ```
   npx wrangler secret put GITHUB_CLIENT_SECRET
   ```
4. `npm run deploy`

Token stays in `sessionStorage` only. Scope is `repo`. Manual PAT field remains.

## How the estimate works

1. Fetch commits (paginated).
2. Sort by author date (when the work was written, not pushed).
3. Split sessions on gaps over ~2 hours.
4. Credit each session: commit span + ramp-up. Human ramp-up scales with
   diff size. Fully AI sessions use model output speed (from trailers when
   present) plus a short review buffer — not human person-hours.

Classic `git-hours` idea. Squashes, rebases, and bulk commits will skew it.

## AI detection

Aggressive by design — any hit counts as AI-helped for timing:

- **AI author** — bot identity (`claude[bot]`, `cursoragent`, Devin, …).
- **AI helped** — [CHAOSS](https://github.com/chaoss/disclosure) / ODS
  trailers (`Co-Authored-By`, `Assisted-By`, `AI-tool`, …), tool footers,
  agent branch prefixes, teaching-voice messages, comment-heavy or bulk
  greenfield patches, in-diff “generated by” markers.

Undisclosed AI in plain code can still slip through. Missing markers ≠
human-written.

## Stack

React 18 · TypeScript · Vite · [Primer](https://primer.style) · [Lucide](https://lucide.dev).
Deployable as a static site (e.g. GitHub Pages).

## Develop

```sh
cp .env.example .env   # optional — needed for OAuth sign-in
npm install
npm run dev
```

`npm run build` typechecks and emits a static bundle to `dist/`.
`npm test` runs the unit tests.

CLI helpers (run against the live GitHub API; `GITHUB_TOKEN` env optional):

```sh
npm run measure -- owner/repo        # print the estimate for a repo
npm run detect-debug -- owner/repo   # dump AI-marker detection stats
```

## Deploy

Cloudflare Worker (static assets + OAuth proxy), custom domain
`gitestimate.sebesta.dev`:

```sh
npm run deploy   # build → dist/ then wrangler deploy
```

Config is `wrangler.toml` (`[assets]` → `dist/`, SPA `not_found_handling`,
route `gitestimate.sebesta.dev`). No `account_id` committed — wrangler uses
the account you're logged into.

Set `VITE_GITHUB_CLIENT_ID` at build time for OAuth sign-in (see `.env.example`).
`VITE_OAUTH_PROXY` defaults to `/api/oauth` (same Worker).
